## 1 引言

### 1.1 目的

本文件规定电子电器智能体（以下简称本系统）的产品定位、本期建设范围、功能需求、知识库要求、非功能要求及验收原则，作为甲乙双方需求确认、分节点交付与验收的依据。

### 1.2 适用范围

本文件适用于部署在甲方指定场所、面向电子电器开发作业的本系统本期建设。本期实现下列五项功能，按功能模块分别交付、分别验收，不得在项目末期一次性交付。

### 1.3 阅读对象

甲方项目负责人、业务使用部门、质量与信息安全部门；乙方产品与实施人员。

## 3 建设目标与原则

### 3.1 建设目标

本系统用于辅助电子电器开发中的规格书参数提取、架构文档填报、IO 口规划、企标测试作业及 CE BOM 编制。使用人员在工位登录后按功能提交材料，系统按既定步骤生成输出物，经人工确认后作为业务结果。

### 3.2 设计原则

1. **场所内运行。** 本系统部署于甲方指定场所的工位计算机，可不连接公网运行。甲方材料不上传公网、不调用公网识别服务、不用于模型训练，不得用于本项目以外用途。
2. **同一环境、分项交付。** 各项功能在同一工位环境登录和使用；按功能模块分别交付、分别验收。
3. **既定步骤，人工确认。** 系统按预先规定的作业步骤生成输出物，不由模型自主规划跨功能任务路径。输出须标示需人工确认的内容；无依据不得填写，不得将未经人工确认的结果视为定稿。
4. **符合甲方模板。** 输出物的格式、表结构、字段及填写口径须完全符合甲方确认的模板。甲方调整模板的，乙方按确认结果更新后再纳入该功能验收。
5. **知识库经确认后使用。** 依据甲方提供的规格书、企标、手册、规则及过往文档，在指定场所形成对应功能的知识库，经甲方确认后使用；变更须经甲方确认后更新。

## 5 总体业务要求

下列要求适用于本期全部功能。

### 5.1 使用对象与使用方式

| 对象 | 使用方式 |
| --- | --- |
| 电子电器开发及相关工程人员 | 工位登录后选择功能、提交当份材料、获取输出物，并在表格中完成人工确认 |
| 质量及项目接口人员 | 提供模板、代表性材料及脱敏要求；对差异按「条目位置、页码、正确值」予以标注，供回归验证 |
| 信息安全管理部门 | 确认指定场所边界、断网条件下的可用性，以及任务记录的查阅与导出 |

本系统以工位客户端交付，客户端基于 krow-agent-sdk。当份材料在工位计算机读取和处理，不离开本机。本期不提供网页访问入口。五项功能按预先编排的步骤执行，不由模型自行规划作业路径。

同一工位环境在同一时刻仅处理一份任务。

### 5.2 登录与权限

经工位登录后使用。登录凭证为甲方开通的电子邮箱及密码。使用权限遵循甲方现场账号管理要求。

### 5.3 材料形式与语言

系统读取 PDF、Word、Excel 等甲方材料。单份材料按一种语言处理（中文、英文或德文）。输出表的表头及清单条目名称采用中文；甲方模板另有规定的，从其规定。

扫描件及以图像形式存在的表格，须先完成文字识别再提取。扫描件处理是否纳入相应功能节点的验收范围，由双方书面确认。

### 5.4 取值与人工确认

1. 写入输出物的取值须来自当份材料：或为材料中直接记载的内容，或为由当份材料已出现的量按双方确认的公式计算所得。
2. 不得以知识库中的典型值、模板中的参考示例或未经当份材料印证的行业经验补填。
3. 不得将「符合某某定律」「符合某某标准」等名称性表述作为参数取值。
4. 按公式计算的缺项：取值栏仅填写计算结果及单位；所用公式及代入量须在备注中写明，并标示为局部对应，供人工复核。
5. 无原文依据的，该栏留空并标示为未检索到，不得推测填写。

第1项核对表的检索结论分为三类，并在表格中以颜色区分，便于筛选：

| 结论 | 含义 | 标识 |
| --- | --- | --- |
| 已检索到 | 当份材料中有明确对应内容 | 浅蓝色 |
| 局部对应 / 需人工复核 | 依据不完整，或为公式推算等须复核情形 | 橙色 |
| 未检索到 | 当份材料中未检索到可填写依据 | 黄色 |

人工核对后，可将状态改为通过、需修改或不适用。

### 5.5 模板变更

甲方调整输出模板的，应以书面方式确认变更内容。乙方据此更新系统及对应知识库，经样例回归后再纳入该功能验收。

### 5.6 安全与记录

1. 甲方材料及运行数据仅在指定场所使用。
2. 不调用公网识别服务，不上传公网，不用于模型训练。
3. 项目结束或甲方提出时，按甲方要求删除或交还相关材料及运行副本。
4. 保留任务起止时间、输入文件及输出文件记录，供甲方查阅并可导出。保存期限由双方确认。

## 6 功能需求

### 6.1 第1项　SOR 参数提取

**完成节点：** 2026-09-30。

**目标：** 自客户规格书提取参数，填入甲方确认的 Excel 核对表，减少人工逐项抄录，并使各字段可回溯至原件。

**甲方须提供：** 现行核对表、目标出表模板、代表性规格书及脱敏口径。

**系统应实现：**

1. 读取 PDF、Word、Excel 格式的规格书。
2. 对明显不属于电控规格书的材料，按不适用处理并输出空表，作为正确分流，不得按电控清单自行填写。
3. 对照甲方确认的电机控制需求清单（条目数量及名称以甲方模板为准）填写核对表。
4. 单份规格书按一种语言处理；核对表表头为中文。
5. 抽出值可回溯至规格书印页及原文摘录；条款号（如有）与页码分列。
6. 标示需人工确认项（见 5.4）。
7. 当份规格书已给出相关量、清单对应项未直接写出时，可按已确认公式计算，并按 5.4 第 4 款标注。

**输出物：** 规格书参数核对表（Excel）。列结构以甲方确认的模板为准。在模板确认前，拟交付列包括：核对状态、分组、需求序号、需求条目、抽出值、页码、条款号、原文摘录、人工填写、复核备注；并以单独工作表提供清单口径（需求说明、必要性、参考示例）。清单口径仅用于说明条目含义，不得作为当份规格书的抽出值。

**验收：** 任取一份核对表，可逐字段回溯至规格书页码与原文摘录。数字化文稿每份处理时间约五分钟，以工位实测为准；扫描件另计。

### 6.2 第2项　架构文档处理

**完成节点：** 2026-09-30。

**目标：** 参考甲方过往架构文档，按甲方确认的栏目辅助填报。

**甲方须提供：** 过往架构文档、填报口径及已有规则（如有）。现行文档无统一固定模板的，架构规则由甲方确认后迭代。

**系统应实现：**

1. 读取过往及当份架构相关材料。
2. 按甲方已确认栏目试填；不能对应至材料的，标示待确认，不得编造架构结论。
3. 知识库收录已确认的栏目定义、互斥规则及常见写法；未确认前仅作材料对照，不得强行套用未确认模板。

**输出物：** 架构文档填报稿，格式以甲方确认的模板为准。无统一模板时，双方须先确认一版栏目后再进行符合性验收。

**验收：** 使用甲方指定的过往文档及当份材料生成一稿，已填栏目可对应至材料出处；无出处栏目为待确认。

### 6.3 第3项　IO+ICD 规划

**完成节点：** 2026-10-31。

**目标：** 依据芯片数据手册及甲方确认的端口命名、约束生成 IO 口初始配置表，供人工确认修改。

**甲方须提供：** 芯片数据手册（如 TC499 等型号）、已确认的端口命名及约束。

**系统应实现：**

1. 自手册提取引脚、复用功能及电气或工作模式等约束。
2. 按甲方确认的命名规则生成初始表。命名及约束未经确认的，仅输出与手册原文的对照，不定稿端口名称。
3. 知识库按芯片型号维护引脚与约束、命名规则及接口字段对应关系。

**输出物：** IO 口初始配置表。须可回溯至手册页码或章节及原文。表中内容供人工确认、修改，确认前不得作为接口控制依据。

**验收：** 指定型号手册一份，初始表中的引脚信息与手册一致；名称及复用的修改在人工填写列完成，系统不得覆盖人工已填内容。

### 6.4 第4项　企标测试项提取与对比

**完成节点：** 2026-11-30。

**目标：** 自企标提取测试项并按项目调整；在具备固定规则时辅助生成测试用例；测试报告与方案按阶段模板填报。

**甲方须提供：** 企标、既有测试项、测试用例规则，以及测试报告与方案模板。

**系统应实现：**

1. 一周内建立清单结构（栏目、层级及与企标条款的对应关系），并与甲方指定供应商沟通后迭代。
2. 提取测试项，并与项目既有测试项对比，区分新增、保留、不适用等。
3. 仅当甲方已提供固定规则时辅助生成测试用例；无规则时不生成。
4. 按甲方确认的阶段模板填报测试报告与方案；缺少材料的栏目留空并标示待确认。

**输出物：** 企标测试清单、测试项对比表、测试用例（在具备规则时），以及按阶段模板填报的测试报告与方案。

**验收：** 清单结构先行确认；对比表可对应至企标条款；用例抽查符合已确认规则；报告栏目与阶段模板一致。

### 6.5 第5项　CE BOM 输出

**完成节点：** 2026-12-19。

**目标：** 自物料手册或器件说明提取长、宽、高、重量等信息，按甲方确认的表格式输出 Excel。

**甲方须提供：** 物料手册或器件说明、甲方确认的 CE BOM 表格式。

**系统应实现：**

1. 按确认的列提取尺寸、重量等；单位换算或原文照录以甲方模板为准。
2. 手册未记载的参数留空，不得以目录或典型值填补。
3. 知识库维护字段对应关系、单位要求及列映射；输出表结构以甲方模板为准。

**输出物：** CE BOM（Excel）。

**验收：** 抽查物料的长、宽、高、重量可对应至手册记载；表头及列序与确认模板一致。

## 7 知识库要求

### 7.1 总体要求

本系统须在指定场所建立与五项功能相对应的知识库，用于识别条目、执行已确认规则、对照模板栏目及登记允许使用的计算公式。知识库仅服务于本系统既定作业，不作为通用问答来源，不得将库内示例数值写入输出物的取值栏。

各功能知识库独立管理版本，独立提请甲方确认。甲方未提供相应材料或条目未经确认的，不得进入该功能的检索与自动填报。

知识库内容、模板及规则的变更，须经甲方确认后更新。

### 7.2 分项知识库

| 知识库 | 对应功能 | 用途 | 不得用于 |
| --- | --- | --- | --- |
| 需求条款与物理关系 | 第1项 | 将当份规格书内容对应至清单条目；区分易混条目；识别常见写法与单位；在当份材料已给出相关量时按已确认公式推算缺项 | 说明「该条目通常取值多少」；以库内典型值填写抽出值 |
| 架构填报口径 | 第2项 | 已确认栏目、填报规则及过往文档中的对应关系 | 绘制新的架构图；给出材料中不存在的架构结论 |
| 芯片与端口约束 | 第3项 | 手册中的引脚、复用及电气约束；甲方确认的命名规则 | 在命名规则未确认时定稿端口名称；替代人工确认 |
| 企标与测试规则 | 第4项 | 企标条款与测试项对应、项目调整规则、用例生成规则、阶段模板栏目 | 在无规则时编制用例；在无模板时自行规定报告格式 |
| 物料与表格式 | 第5项 | 手册字段与长、宽、高、重量等列的对应及单位要求 | 以目录典型尺寸填补手册未记载的参数 |

### 7.3 更新与追溯

知识库在指定场所内维护。乙方整理条目后提交甲方确认；确认并允许使用的范围方可被相应功能调用。更新须保留版本，必要时可恢复至既往确认版本。

抽取或填报错误时，应修订对应知识库条目及规则并作样例回归，不得仅以调整模型提示代替知识库变更。

### 7.4 记忆范围

本系统记录当次任务进度、输入与输出文件、所使用的模板及知识库版本。不保存跨任务的使用人员偏好或会话历史。企业口径以甲方确认的模板和知识库为准，业务人员在输出表格中修订。

---

## 8 非功能要求

### 8.1 架构与运行

工位部署采用接入、识别、处理、输出四层结构，工位客户端基于 krow-agent-sdk，具体见《技术架构说明书》。断开公网后，在指定场所识别能力可用的前提下，各功能仍应能够运行。

### 8.2 处理时间

第1项数字化文稿每份约五分钟，以工位实测为准。扫描件识别与处理时间另行统计，不纳入上述五分钟口径。

### 8.3 并发

同一工位环境同一时刻仅执行一份任务；后续任务须等待当前任务结束后再提交。

### 8.4 模型与费用

识别与提取结合指定场所内部署的大模型。更换模型或调整建设范围的，须经双方书面确认。工位及指定场所部署运行期间，不向公网模型服务支付调用费用。

---

## 9 甲方配合事项

代表性材料、现行模板及脱敏口径是按真实表结构验收的前提。甲方材料未齐的，该功能可进行流程演示，但不得视为已完成符合模板的验收。

| 功能 | 材料未提供时的影响 |
| --- | --- |
| 第1项 | 无法按甲方真实清单条目验收提取是否正确 |
| 第2项 | 无确认栏目或模板时，无法验收输出物完全符合模板 |
| 第3项 | 无手册或端口命名规则时，无法验收可确认的初始配置表 |
| 第4项 | 无企标无法建立清单；无用例规则则不生成用例 |
| 第5项 | 无确认的表格式时，无法验收列结构 |

如需脱敏，可对客户名称、联系人、订单号、价格等作遮盖。电压、电流、试验条件、尺寸、重量、页码、表头及单位等与验收直接相关的内容不宜遮盖，否则无法判定提取是否正确。

---

## 10 验收要求

各项功能在同一工位环境登录和使用，按功能模块分别交付、分别验收。智能体验收按下列六类进行。

| 类别 | 验收内容 | 验收方式 |
| --- | --- | --- |
| 技术架构与模型能力 | 工位客户端基于 krow-agent-sdk。工位部署采用接入、识别、处理、输出四层架构。接入层提供工位登录与使用权限；识别层在甲方指定场所完成本机识别，读取 PDF、Word、Excel 等材料；处理层按本期五项功能分别实现提取、填报或对照，并结合本机大模型；输出层按甲方确认的模板生成业务文件。作业路径由本系统预先编排，不采用开放式 Agent。本期不含原理图检查、布局检查、方案比对、比较报告、架构图绘制及软件建模求解 | 工位演示四层链路完整跑通；断开公网后各功能仍可运行 |
| 知识库与记忆能力 | 依据甲方提供的规格书、企标、手册、规则及过往文档，在指定场所形成对应功能的知识库，经甲方确认后使用；知识库内容、模板及规则变更经甲方确认后更新。第1项核对表应能回溯至规格书页码及原文摘录，并标示供人工确认项 | 任取一份核对表，可逐字段回溯至规格书页码与原文 |
| 任务执行效果 | 各功能按既定步骤生成对应输出物，由人工确认。第1项数字化文稿每份约五分钟，以工位实测为准 | 按双方确认的样例在工位实测 |
| 安全与合规 | 甲方材料及运行数据仅在指定场所使用，不调用公网识别服务，不上传公网，不用于模型训练，不得用于本项目以外用途；项目结束或甲方提出时按甲方要求删除或交还。经工位登录后使用，并保留任务起止、输入文件及输出文件记录供甲方查阅 | 断网环境下功能可用；任务记录可查、可导出；出网连接在网络侧核实为零 |
| 工程成熟度 | 服务期内提供版本维护、缺陷响应及样例回归；甲方可提供样例用于回归确认；乙方在工位交付时完成使用培训 | 提交版本更新说明与样例回归报告；培训完成并留存记录 |
| 成本与商务 | 工位及指定场所部署运行，不向公网模型服务支付调用费用 | 核对运行期间无公网模型调用产生的费用 |

第2项与第1项完成节点相同。第1项按本章及甲方确认模板验收；第2项在架构模板及过往文档齐备并经甲方确认栏目后，按是否符合模板验收。第3项依据芯片数据手册及甲方确认的端口命名、约束生成 IO 口初始配置表，供人工确认修改；手册或命名、约束未经确认的，不视为完成节点验收。材料未齐时，不视为该功能已完成节点验收。
