# 电子电器 · SOR填表：网页端与客户端（书面口径）

给甲方确认用。两种壳、一套出表流水线。规格书整文件不出公网。

```
  操作员 ──► 客户端独立窗口 / 网页端浏览器
               │
     ┌─────────┴─────────┐
     │                   │
  客户端              网页端
  工位安装包           指定场所内网
  原生窗口+嵌入Python    内网 HTTPS
     │                   │
     └─────────┬─────────┘
               ▼
     同一套 electrical 流水线
     读文件 → 分流 → 规则 → 分段 JSON → Excel
               │
               ▼
     现场 Krow Server（识别）
     规格书整文件不到公网
```

## 五句话

1. **一套流水线**：出表主路径不变（读文件 → 分流 → 规则 → 分段 JSON → Excel），不改成开放式 `agent.run()`。登录仍是邮箱 + 密码。
2. **客户端**：工位安装 Windows 包。独立窗口 + 嵌入 Python（不是 Electron）。规格书只在这台电脑上读，服务只绑 `127.0.0.1`，外网打不进来。
3. **网页端**：同一套程序部署在甲方**指定场所内网**。员工用浏览器打开内网地址，把规格书上传到场所应用机；文件落场所磁盘，识别仍打现场 Krow Server。
4. **识别落点**：只改 `config.ini` 的 `server_url`。联调可暂用契约验证，生产切现场。不把规格书整文件传到 `api.krow.cn`。
5. **不做什么**：不做公网 SaaS（不是「krow.cn 打开就出表」）；不把页面直接暴露到公网；不用手机号验证码登录本产品。

## 请甲方书面确认（网页端）

网页端允许规格书**离开本人电脑、落到指定场所内的应用机**，但**不出公网**。

- [ ] 同意：网页端 = 指定场所内网网站，文件上传到场所服务器。
- [ ] 不同意：只要客户端（规格书不离开工位电脑）。
- [ ] 另立范围：若坚持「公网网站 / 在 krow.cn 打开就出表」，与现有协议（指定场所、规格书不出公网、页面不对外网开放）冲突，需另签范围，本期不按公网 SaaS 交付。

## 给甲方的东西

| 形态 | 交付物 | 第 1 项怎么验 |
| --- | --- | --- |
| 客户端 | Windows exe/zip + 使用说明 + 现场四项清单 | 工位安装 → 邮箱登录 → 拖文件 → 下载核对表 |
| 网页端 | 场所部署说明 + 同一程序 + 内网 URL | 内网打开 → 同一邮箱登录 → 上传 → 下载核对表 |

本期只保证第 1 项出表在两种壳上都能跑。网页端先按全站串行一份（与协议「工位一份」一致）。扫描件 OCR 是否纳入，仍须双方书面确认。
