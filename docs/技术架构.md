## 1 引言

### 1.1 目的

说明本系统如何分层实现、如何部署于指定场所，以及识别、处理、知识库与输出如何衔接，使五项功能按既定步骤运行。

### 1.2 架构原则

1. 作业路径预先编排。模型仅在既定步骤内辅助识别与提取，不自行规划步骤，不变更甲方模板，无材料依据不填写。
2. 以工位智能体客户端运行。当份材料在工位计算机读取和处理。
3. 甲方材料整文件不传输至公网。提交识别服务的内容为分段文本或扫描页图像。
4. 各功能使用各自的知识库；未经甲方确认的内容不参与自动填报。

## 2 总体架构

本系统采用接入、识别、处理、输出四层结构。五项功能共用接入、识别与输出约束，处理层按功能分别实现。

| 层次 | 职责 | 说明 |
| --- | --- | --- |
| 接入层 | 登录与使用权限 | 电子邮箱及密码；同一工位同一时刻仅处理一份任务 |
| 识别层 | 读取 PDF、Word、Excel 等材料 | 在指定场所完成。数字化文稿读取文字及表格；扫描件及图像类表格先识别文字 |
| 处理层 | 按功能提取、填报或对照 | 先按已确认规则填写，空缺项再分段提取；无法提取则留空 |
| 输出层 | 按甲方确认的模板生成文件 | 标示需人工确认项，并保留任务记录 |

处理顺序如下。

| 顺序 | 环节 | 内容 |
| --- | --- | --- |
| 1 | 接入 | 登录后选择功能、提交当份材料 |
| 2 | 识别 | 在指定场所读取材料；必要时进行文字识别 |
| 3 | 处理 | 文档分流，对照知识库，按规则填写，对空缺项提取 |
| 4 | 输出 | 生成模板文件，供人工确认 |

工位智能体客户端基于 krow-agent-sdk 实现，与指定场所识别服务配合完成登录、文档读取及分段识别。

| 组成部分 | 职责 |
| --- | --- |
| krow-agent-sdk | 工位登录、领取场所内识别凭据、读取办公文档、向识别服务提交分段请求 |
| 处理编排 | 按功能执行固定步骤：分流、规则填写、分段提取、生成输出物 |
| 指定场所识别服务 | 结构化提取及文字识别 |

| 项目 | 说明 |

| 对外访问 | 客户端不对公网开放 |

## 4 识别与模型

识别服务部署于甲方指定场所。使用人员经工位客户端登录后取得现场识别凭据，再调用场所内模型。识别请求由既定步骤按段发起，不进行开放式对话。

| 能力类型 | 用途 | 约束 |
| --- | --- | --- |
| 结构化提取 | 从已识别文本中得到可写入模板的结果 | 作为取值来源 |
| 文字或版面识别 | 将扫描件、图像表格转为文字 | 只提供文字，不直接作为核对表取值 |

更换模型须双方书面确认。工位及指定场所运行期间，不向公网模型服务支付调用费用。

数字化文稿先按已确认规则填写，仅将空缺部分送入模型，避免将整本材料一次性输入。

---

## 5 处理架构

五项功能互不混用输出模板。所需材料缺失时，不生成对应输出物，并提示原因。页码、颜色标识、公式备注等填写口径见《产品需求与设计说明书》。

### 5.1 共同机制

| 事项 | 实现 |
| --- | --- |
| 进度与控制 | 工位界面展示当前步骤；支持暂停、继续；支持结束任务并输出已生成内容 |
| 格式校验 | 提取结果不符合约定时，该段重试；仍不符合则该段空缺，其余继续 |
| 分流 | 材料明显不属于该功能适用对象的，按不适用处理，不套用该功能模板填写 |

### 5.2 第1项　SOR 参数提取

| 步骤 | 内容 |
| --- | --- |
| 1 | 读取 PDF、Word、Excel；表格按单元格读取 |
| 2 | 扫描件或图像表格先做文字识别 |
| 3 | 判断是否为电控规格书；否则按不适用输出空表 |
| 4 | 按已确认规则填写；当份材料已给出相关量时，可按已确认公式推算 |
| 5 | 对空缺项分段提取 |
| 6 | 合并结果，排除明显误配，按模板输出核对表 |

### 5.3 第2项　架构文档处理

| 步骤 | 内容 |
| --- | --- |
| 1 | 读取过往及当份架构相关材料 |
| 2 | 按甲方已确认栏目对齐 |
| 3 | 对照过往文档试填；无出处标示待确认 |
| 4 | 按确认模板输出填报稿 |

无统一模板时，双方先确认栏目后再实现输出。本期不含架构图绘制。

### 5.4 第3项　IO+ICD 规划

| 步骤 | 内容 |
| --- | --- |
| 1 | 读取芯片数据手册 |
| 2 | 提取引脚、复用及约束 |
| 3 | 按已确认命名规则生成 IO 口初始配置表 |
| 4 | 保留人工填写列，供确认修改 |

命名规则未经甲方确认的，仅输出与手册的对照。输出表须可回溯至手册记载位置。

### 5.5 第4项　企标测试项提取与对比

| 步骤 | 内容 |
| --- | --- |
| 1 | 读取企标，建立或更新清单结构 |
| 2 | 与项目既有测试项对比 |
| 3 | 在已确认规则下辅助生成测试用例；无规则则不生成 |
| 4 | 按阶段模板填报测试报告与方案 |

### 5.6 第5项　CE BOM 输出

| 步骤 | 内容 |
| --- | --- |
| 1 | 读取物料手册或器件说明 |
| 2 | 按甲方确认的列提取长、宽、高、重量等 |
| 3 | 按模板处理单位 |
| 4 | 输出 Excel |

手册未记载的参数留空。

## 6 知识库架构

### 6.1 作用

知识库部署于指定场所，用于将当份材料对应到甲方清单或模板栏目，执行已确认的互斥与单位要求，并登记允许使用的计算公式。知识库不向输出物提供示例性数值，不将甲方材料或库内容提交至指定场所以外。

### 6.2 管理流程

1. 确定该功能知识库的适用范围与除外事项。
2. 登记甲方材料来源及不得带离场所的要求。
3. 整理为可核对的条目。
4. 在指定场所生成程序使用的版本，并保留历史版本以便回退。
5. 经甲方确认并允许启用后，方可被对应功能调用。
6. 未提供的企标、手册、过往文档不进入检索。变更须再次确认。

### 6.3 分项内容

| 功能 | 知识库内容 |
| --- | --- |
| 第1项 | 需求清单条目、易混项、规格常见写法、物理量关系及允许用于推算的公式 |
| 第2项 | 已确认架构栏目、填报规则、与过往文档的对应关系 |
| 第3项 | 分型号的引脚与约束、端口命名规则、接口字段对应 |
| 第4项 | 企标条款与测试项、项目调整规则、用例规则、阶段模板字段 |
| 第5项 | 物料字段与输出列对应、单位要求 |

第1项自规格书匹配清单条目时，仅对甲方已确认且验证通过的条目启用自动匹配。

### 6.4 与模型的分工

|  | 知识库 | 场所内大模型 |
| --- | --- | --- |
| 作用 | 条目对应、已确认规则、允许的公式、模板栏目 | 从当份材料中定位语句与数值 |
| 禁止 | 将库内示例写入取值栏 | 以模型固有知识补写材料中不存在的数据 |
| 更新 | 条目修订并经甲方确认后启用 | 更换模型须书面确认，不能替代知识库更新 |

## 7 数据流与安全

### 7.1 数据流

| 顺序 | 位置 | 内容 |
| --- | --- | --- |
| 1 | 工位计算机 | 存放当份材料 |
| 2 | 指定场所内 | 解析文件；必要时识别文字 |
| 3 | 指定场所内识别服务 | 接收分段文本或扫描页图像 |
| 4 | 指定场所内 | 结合知识库生成结构化结果 |
| 5 | 工位约定目录 | 写入模板文件 |

甲方材料整文件不进入公网。知识库与材料均不得带离指定场所。项目结束或甲方提出时，按甲方要求删除或交还输入、输出及缓存副本。

### 7.2 安全控制

| 要求 | 实现要点 |
| --- | --- |
| 不调用公网识别服务 | 仅配置指定场所内识别服务 |
| 不用于模型训练 | 不提供将甲方材料用于训练的功能 |
| 登录后使用 | 电子邮箱及密码 |
| 断网可运行 | 识别服务与知识库位于指定场所内 |
| 访问范围 | 客户端不对公网开放 |

### 7.3 任务记录与审计

记录当次任务的进度、起止时间、输入文件、输出文件、所用模型及知识库版本，供甲方查阅并可导出。不保存跨任务的使用人员偏好或会话历史。保存期限由双方确认。第1项核对表中的页码与原文摘录作为业务追溯依据。

任务失败时停留在相应步骤并提示原因。场所内模型用量以甲方识别服务侧记录为准。
