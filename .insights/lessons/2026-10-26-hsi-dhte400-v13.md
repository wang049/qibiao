# 2026-10-26 HSI 默认模板改为 DHTE400 V1.3

- 状态：active
- 条目：HSI 出表
- 闸门：`tests/test_hsi.py`（`test_dhte400_keeps_atom_port_name_cover_and_history`、`test_gm_pwm_is_read_from_the_pin_definition_column`、`test_dhte_adc_header_reads_symbol_beside_signal_name`、`test_phase_currents_must_share_a_channel_across_groups`）

## 代价

按吉利模板的列去读写 2026-10-23 的 DHTE400 V1.3，会把 DTM 当成方向、把功能类别当成端口名，并删掉硬件版本、死区、热泵这些表。封面的修改人和修改要求也会被目录重写盖掉。

## 反事实

不按这版表头定位列，下一次端口名仍从 J 列读，`PWM_M_AH_GM` 读成 `PWM`，GM 上下桥不会按同一个 ATOM 核对。三相电流若仍从 Ball 列取符号，`IA_S/M_TM` 对不上 AN0。生成时若继续删表、重写封面，`0_硬件版本识别` 和「殷桂来 / 修改原理图网络名」不会留在结果里。

## 二级依据

- 模板文件：`DHTE400_HSI_V1.3_20261023_release.xlsx`，封面为 `Cover`。端口表名 `2_Port Assignment `（末尾有空格）。表头在第 3 行。
- 模板正文仍是 B 为符号、C 为球号（表头文字与正文对调）。读模板时按正文。写出的表按表头：B 为球号、C 为引脚符号。见 `2026-11-04-hsi-ball-and-symbol-columns`。G 为 ATOM，H 为 DTM，I 为 Direction，J 为 Function，K 为星驱原理图网络，L 为端口名，M 为说明。`P02.1` 为 `PWM_M_AH_GM`，`GTM0_ATOM1_CH1` / `CDTM1 DTM4_1`。`AN0` 为 `IA_S/M_TM`，方向 Input，功能 Analog。
- ADC 表 `3_ADC Table`：第 4 行 `Signal name` 在 F 列，符号在 D 列。TM 主电流为 Gr0/Gr1/Gr5 的 Ch0，GM 为 Gr2/Gr3/Gr4 的 Ch1。`TMBU`、`GMBU` 不计入这三相。
- SPI 表名为 `4-SPI总线`。变更记录第 1 行含「版本」，已有 v1.0 至 v1.3 保留。封面 D1 为「修改人」，E 列为修改要求。
- 同一分配规则用于 P1、GM、TM：同一桥的 PWM 在同一个 ATOM，同一相上下桥为同一通道的互补输出。

## 闸门

`test_dhte400_keeps_atom_port_name_cover_and_history`：读出 AN0、P02.1 的方向、功能和端口名；写出后 ATOM、DTM、星驱网络还在原列，封面修改人和 v1.3 变更还在，硬件版本表还在。
`test_gm_pwm_is_read_from_the_pin_definition_column`：端口名在 L 列时，GM 上下桥 ATOM 不一致要标出。
`test_dhte_adc_header_reads_symbol_beside_signal_name`：符号在 Signal name 左边两列时，TM 三相挤在同一 group 要标出。
`test_phase_currents_must_share_a_channel_across_groups`：DHTE400 里已配好的三相电流不标冲突。
