## 专家怎么签

每条只答四问（在「专家」列打勾或改序号）：

1. 对应清单哪几条（源表序号，如 #13）
2. 进哪一层：gloss / 别名 / exclude / physics / 闸门 / **不进本库**
3. 能否填核对表：**否**（本库红线）
4. 高压安全、功能安全、性能参数须责任人署名

底稿三类记录的处理：

| 底稿判断 | 检索/入库 | 禁止 |
| --- | --- | --- |
| 可入库 | 连同适用边界保存 | 丢掉条件只留一句结论 |
| 待项目确认 | 返回「还缺哪些条件」 | 把经验数字当已批准值 |
| 误用命题 | 返回「该说法不成立」和修正 | 只索引错误标题 |

《电子与电器工程知识》当目录和公式导航，等拆成带来源的卡片后再议。附录 D 模板可用，本批不按 18 卷整卷入库。
