# 电控条款知识库 · 怎么操作

本库只服务第 1 项出表：**认这条 DPR 是清单哪一项、别填错列**。  
抽出值来自**当份规格书**：直接写出的数，或由当份已出现的量按 `physics.yaml` 里 `derive: true` 的公式算出的缺项。  
算出的格子：抽出值写算出的数（#68 升压输出功率写 kW 点值并括注代入的 V×I）；所用公式和代入量写在核对表 **「复核备注」**（并标局部对应）。不得把电压区间乘成 kW 范围。  
库里的示例、企标典型值不能写入核对表。不要把「符合欧姆定律」这类句子当成抽出值。当份未给出、条目在企标挂了试验方法时，抽出值仍为未检索到，复核备注写企标条款与方法号。无方法号的空项同样未检索到。仍不得写「通常」寿命或试验箱边界，也不得把「参考 标准号」写入抽出值。  
`derive: false` 的公式只用于读表/校验（例如 \(2U+1000\)、峰值\(\sqrt{2}\)有效值、\(I^2R\) 整机热损失、\(k_e/k_t\)、升压占空比）。

日常只做三件事：改卡片 → 发布 → 甲方确认后再开检索。

## 文件在哪

| 你改什么 | 路径 |
| --- | --- |
| 定范围 | 本文件 + `catalog.yaml` 的 `scope` |
| 收源、密级、能否出场所 | `catalog.yaml` |
| 120 项卡片（语义/别名/禁配） | `docs/clause_lexicon.yaml`（源表 #18/#19、#26/#27 已删；知识库仍用源表序号，核对表需求序号 1–116） |
| 物理关系（欧姆定律、\(P=UI\)、放电 RC 等） | `physics.yaml`（`fill: false`） |
| 哪几条已确认、哪几条可检索 | `registry.yaml` |
| 给人看的确认稿 | 物理关系给专家：`专家审核稿-物理关系.md`；清单未定义的 7 问：`甲方确认稿.md`；120 条别名细节：`docs/清单与规格常见写法.md` |
| 元规则 | `.krow/AGENTS.md`（认条≠取值；不填格；不开放规划） |
| 摩擦复盘 | `.krow/lessons/`（给人看、给召回，不写入抽出值） |

发布产物（不要手改）：

- `docs/clause_lexicon.json` — 出表程序读取
- `published/keyword_index.json` — 关键词认条
- `published/graph.json` — 易混/同组/物理关系边
- `published/manifest.json` — 版本、出处、检索开通名单
- `releases/<版本>/` — 快照，用于回滚

## 七步对应操作

### 1. 定范围

改 `catalog.yaml` 里 `scope.answers` / `scope.does_not`。  
当前约定：回答「这句话是哪一条、和哪一条互斥、表格列是什么物理量」。  
当份规格书已给出相关量时，可用公式推算缺项。  
不回答「这条通常应该是多少」、不用库典型值填空。

### 2. 收源并分类

每来一份甲方材料，在 `catalog.yaml` 的 `sources` 加一条：`id`、名称、谁提供、密级、`leave_site`（出场所：一律 `false`，整库不出公网）。

### 3. 结构化（卡片）

- 清单条目：改 `docs/clause_lexicon.yaml` 对应 `id`（gloss、强/弱别名、exclude、cues、see、unverified）。  
- 企标：改 `enterprise_std.yaml`（定义、试验方法号、对照清单序号）。**`fill: false`**。评价看当份 DPR，不得把「通常」寿命或试验箱边界写入抽出值。  
- 物理：改 `physics.yaml`，写清 `law`、`use`（read_table / validate / derive）、**`fill: false`**。`derive: true` 才允许用当份原文里的量计算。  
  当前会算：\(R=U/I\)、\(P=UI\)、\(P=\sqrt{3}UI\)、\(T=9550P/n\)、\(I=P/U\)（升压直流）、\(I=P/(\sqrt{3}U)\)、\(t=RC\ln(V_0/60)\)、\(\eta=P_{out}/P_{in}\)、\(P_{loss}=P(1-\eta)\)。  
- 改完同步人读稿 `docs/清单与规格常见写法.md`（只增不删口径）。

### 4. 建索引

在本机执行（不上云、不做公网向量）：

```bash
cd /Users/wwj/电子电器项目/electrical-krow
python scripts/publish_knowledge.py
```

会重建关键词倒排索引，以及由 `see` / 禁配 / conflict / 物理卡片连成的图谱。  
近义目前用「别名折叠 + 弱别名索引」，不把规格书或库送到公网向量服务。

### 5. 确认后发布

`registry.yaml`：

- `default_status: draft` — 未确认，**不进选段检索**
- `confirmed` — 甲方已确认卡片，仍未开检索
- `published_retrieve` — 已确认且允许选段（现在只有耐电压 #14）

确认一条：把它的序号写入 `confirmed`，需要开检索再写入 `published_retrieve`，然后改 `version`，再跑 `publish_knowledge.py`。  
每次发布会在 `releases/<version>/` 留快照。

回滚：

```bash
python scripts/publish_knowledge.py --rollback 2026-09-03.1
```

### 6. 接到应用

出表已读 `docs/clause_lexicon.json`。命中条款时出处来自 `manifest.json` 的 `citation`（清单条目号 + 知识库版本）。  
程序不得把 `xlsx.example` 写进抽出值。当份原文已有电压/电流等输入量时，可以按公式推算缺项并标局部对应。

### 7. 运维

抽错了按「一次代价 → 一篇复盘 → 一道闸门」结案，不要只改模型提示词。

1. **先召回**同主题复盘（读取侧，禁止半边墙）：

```bash
python scripts/recall_lessons.py 115
python scripts/recall_lessons.py 升压充电
```

2. 在 `.krow/lessons/` 按 `_TEMPLATE.md` 新增一篇，**必须**写清两行：
   - **反事实**：不这样改，下次会怎样错。
   - **二级依据**：清单 gloss / 专家格子（序号 + 印页 + 正确口径）/ 条款号。
   写不出这两行：交账本，不是交代码。
3. 判断改卡片还是改出表规则（认错列 → YAML；取值过满/过空 → `electrical` 闸门）。
4. 落下机器闸门（规则或 unittest）。没有闸门则复盘保持 `candidate`，不算结案。
5. 改 YAML / `physics.yaml` 后跑发布，并回归：

```bash
PYTHONPATH=. python -m unittest tests.test_clause_lexicon tests.test_knowledge tests.test_lessons
```

样例回归仍用甲方标过的核对表（格子 / 页码 / 正确值）。  
`.krow/lessons` 与 `AGENTS.md` 不得写入抽出值。
