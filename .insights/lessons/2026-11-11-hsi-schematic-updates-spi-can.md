# 2026-11-11 原理图网络名写入已有的 SPI 和 CAN 行

- 状态：active
- 条目：HSI 出表
- 闸门：`tests/test_hsi.py`（`test_schematic_updates_matched_spi_and_can_nets_only`）

## 代价

按原理图归档只改端口表和 ADC 信号名。SPI、CAN 里对得上的脚仍是模板上的网络名和复用，后面整页看起来像没生成。

## 反事实

不把原理图网络名写进已有的 PIN / Net Name 行，下一份 `P00.8` 的 SPI 网络名仍是 `CSN3_M/T_SPI3`。对不上的脚若追加到表尾，`P99.1` 会变成新的一行。波特率或中文说明若被改掉，`2M` 和「底盘CAN2片选」就不再是模板原文。死区时间若被清掉，`1.6` 会消失。

## 二级依据

- 原理图归档不改模板底色。只有这次写进格子的内容标绿，并在核对状态写「待人工复核」。
- SPI、CAN 里已经有的脚才改网络名。复用只在和这一页相符时改：SPI 页认 QSPI/SPI，CAN 页认 CAN 的 TXD/RXD。
- 说明、方向、波特率不改。已经有引脚行时，表里没有的脚不追加。整页只有表头时，把原理图里属于 SPI 或 CAN 的脚写成新行；`GPIO` 不进这两页。没有 PIN / Net Name 的页，包括死区和温度，保持模板。

## 闸门

`test_schematic_updates_matched_spi_and_can_nets_only`：`P00.8` 的网络名和复用改成原理图上的，说明和 `2M` 还在。`P01.3` 不动。`P99.1` 不追加。CAN 的 `P14.0` 网络名和复用更新，说明还在。死区 `1.6` 还在。
