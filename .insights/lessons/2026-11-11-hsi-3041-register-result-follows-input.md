# 2026-11-11 3041 用下拉选 0、1、2，寄存器值跟着变

- 状态：active
- 条目：HSI 出表
- 闸门：`tests/test_hsi.py`（`test_register_value_drives_the_3041_result`）

## 代价

位值是从 Register Value 拆出来的公式，格子里不能改。要改配置只能改十六进制。Value 还指向外部「选择」表，打开是 `#REF!`。

## 反事实

位值继续做成从 `F8` 拆出来的公式，下一份不能在 `E8` 里下拉选 0、1、2。下拉若允许超过掩码，两位的字段会出现 4。再跑一次若再加一套下拉，同一格会有两份校验。富士型号已写入「选择」时若被盖掉，B2 的下拉会指错。

## 二级依据

- 模板 `E8` 行上是 bit15，掩码 3，占 bit15 和 bit14。`E10` 行上是 bit13，同一掩码应占 bit13 和 bit12。公式写成右移 13 位时会占用 bit14。
- 不超过 8 个数的字段用下拉。掩码大于 7 的字段用 0 到掩码的整数，不铺成长列表。
- 纳秒公式仍引用位值格，例如 `G18`。器件型号下拉是 B2。选项中文不在这本表里，不另写。

## 闸门

`test_register_value_drives_the_3041_result`：`E8` 为 1，下拉止于 3。`E10` 按 bit13 对齐后为 0，拼进 `E10*2^12`，不再用 `2^13`。`E18` 掩码 63，校验是 0 到 63 的整数，不是长下拉。`G18` 仍引用 `E18`。再跑一次不追加第二套校验。
