# 2026-11-03 端口表的黄紫底在列样式和条件格式上

- 状态：active
- 条目：HSI 出表
- 闸门：`tests/test_hsi.py`（`test_board_pins_drop_template_yellow_and_purple_rows`、`test_manual_ports_drop_template_yellow_and_purple_rows`）

## 代价

按手册或按原理图写出端口表后，数据行上的黄、紫行样式已经去掉，工作表视图也写成了普通视图。空列仍带着模板列样式 `theme="0"`，WPS 把这层填色画成黄底。条件格式还按 A/B/C 把格子涂成绿、蓝紫和黄。列样式一直登记到第 16384 列，分页预览就印出「第 42 页」这一串页码。

## 反事实

只删表头以下的行样式，下一次打开 `2_Port Assignment`，没有单元格的列仍是黄的，N/O/P 里标成 B 或 C 的格子仍是紫的或黄的。列范围仍到 XFD 时，分页预览的页码还是「第 42 页」「第 83 页」。

## 二级依据

- `output/HSI--20261103.xlsx` 的端口表：数据行没有行样式，视图已是 `normal`，列 A–R 和 S–XFD 的列样式仍是填充 `theme="0"`。
- 同一张表有 67 条条件格式。值为 C 的底色是 `FFFFFF00`，值为 B 的底色是 `FF3366FF`。
- 模板列记录 `min="19" max="16384"`。截图上的页码间隔是 41，对应这一整段列被算进打印页。

## 闸门

两则测试都检查：表头以下不再保留模板行样式；列填充不是实心色，列范围不超过 200；条件格式清空；视图是普通视图，左上角回到 A1。
