# 120 项清单与规格常见写法 · 扩展版 v0.1

来源：客户《电机控制需求清单》（XCM控制器前期设计最小化输入清单，20260821V1）共 120 条。本版在原字典基础上做词义扩展，**只增不删**；原字典里无法核实的写法移入「未核实」栏，不作强别名。

## 别名分级（新增）

- **强别名**：整词、跨条目唯一，命中即可计分。
- **弱别名**：整词但多个条目共享（如「峰值功率」P1/P3 都有），须配合判别词（P1/P3、Boost、电池连接/断开、稳态/动态、存储/工作 等）或单位闸门才计分。文末附弱别名索引。
- **定位词**：裸词如 BOOST / P1 / P3 / 冷却 / 温度 / 电压，只用于缩小段落范围，永不计分。
- **单位闸门**：每条给出期望的数值形态；候选句若不含该形态，即使别名命中也降权。
- **排除**：含这些词的句子不配到本条（括号内指向应归属的条目）。
- 别名来源：未标注 = 行业通用术语；[原字典] = 沿用原字典；[清单] = 取自清单 D/E 列。企业标准号只保留清单原文。


## 怎么用

1. 规格对不上清单全称时，用「规格常见写法」整词去搜，不要把清单名切成「电压」「电流」「安全」。
2. 本表是词典 + 禁配表，用来读懂 DPR 并对齐 120 项。取值只来自这一份原文，禁止用行业常识或清单示例值补空。
3. 大模型只判断原文有没有写、写的是不是这一条。「规格常见」只出现在认条提示里，不会当成抽出值。
4. 选段检索先只开通已验证条目（目前：耐电压 → 耐压 / hipot）。弱别名不进选段打分。不要一次把 120 条都灌进选段。
5. 同名重复项里，绝缘电阻、耐电压、冷却回路压降、网络安全、振动：共用写法且抽出值应对齐。防腐等级与防腐要求互补（等级 vs 标准号）；控制器重量与重量要求口径不同；母线纹波、高压安全纹波、升压纹波不要互填。
6. 词条真源：`docs/clause_lexicon.yaml`。发布：`python scripts/publish_knowledge.py`（见 `docs/knowledge/操作.md`）。机器可读：`docs/clause_lexicon.json`。
